# Usability findings: SVG vs GLB vs simulation (E1-5)

Status: **not started.** The visual lab opens from the bicycle lesson ("See it in action" or "Compare ways of seeing it"). In the session panel, leave **Visual order** on Auto: the participant number picks one of three Latin-square orders.

## What we're testing

1. Which format helps learners answer a gear question correctly (`visualCheck` events)?
2. Which format do they say helped most (`visualPreference`)?
3. How long each format takes to appear on the participant's own device (`visualLoaded`, `loadMs`)?
4. Does anyone struggle with dragging the 3D model or using the sliders?

Questions follow position, not format, so question difficulty is balanced across formats:

1. 34 front teeth and 17 back: how many wheel turns per pedal turn?
2. Which turns faster: the front ring or the back cog?
3. A bigger back cog: what happens to pedalling?
