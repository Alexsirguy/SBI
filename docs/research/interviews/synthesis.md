## Method

1. Put one observation per sticky note (or row), tagged with the participant code and segment.
2. Cluster the notes into themes, and name each theme as a user need ("I need to know the answer is checked").
3. Score each insight:
   - **Frequency:** how many participants it showed up for.
   - **Severity:** 1 to 3. A 3 blocks use or trust.
   - **Segment spread:** how many segments it showed up in.
4. Priority = frequency × severity. Break ties by segment spread.
